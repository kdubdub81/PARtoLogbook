PAR → Logbook

Tool to convert PAR files to an excel spreadsheet logbook

Disclaimer — use at own risk.
  • The creator of this tool takes no responsibility for your logbook or your job application.
  • PAR files themselves are not 100% accurate and may have missing hours and sectors.
  • PAR files do not contain SIM activities.
  • This tool may capture jumpseat observation sectors (prior to line training on a 2 crew a/c) as SO time as they are displayed the same in the PAR files. If your PAR files contain your line training, these observation sectors may need to be removed.
  • This tool does capture ICUS flying but does not place it in the ICUS column as there is no way of identifying ICUS in the PAR file.
  • Basic checks are conducted to find and advise the user prior to exporting of any sectors that are suspect as actually being a deadhead.
  • Please de-select aircraft codes found in the PAR file that you don't want to pull flying hours for prior to pressing Generate.
  • The outputted Excel file has its sheets locked down for formatting and formula protection. If you NEED to adjust the file more than data entry, the protection password is the number one — but be careful, you may break summary formulas if you start deleting rows and moving columns around etc.
All said and done, across a variety of testing completed, the PAR file data is usually accurate to within 50 hours over a 15 year period.

⚠️ Custom Logbook — Please Read
  • This feature is for pilots who have their own personal Excel logbook with a different column layout to the one generated by this tool.
  • You must map each data field to the correct column in your logbook below. Incorrect mappings will put data into the wrong cells.
  • The tool will copy cell styles from the style reference row you specify (this should be an existing data row in your logbook).
  • The Summary sheet will not be touched — any summary formulas in your logbook must be managed by you.
  • Year headers and month spacing rows will still be inserted. If your logbook doesn't use these, you may need to remove them manually.
  • Set any field to "Skip" if your logbook doesn't have a column for it.
